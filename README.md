# Company Portal — วิธีเอาขึ้นออนไลน์

โฟลเดอร์นี้คือเว็บพร้อมใช้งาน (React + Vite + Tailwind)

## ขั้นตอนย่อ (ทำผ่านเว็บเบราว์เซอร์ล้วนๆ ไม่ต้องเขียนโค้ดเพิ่ม)

1. สมัคร/ล็อกอิน https://github.com แล้วสร้าง repository ใหม่ (New repository)
2. ในหน้า repo ว่างเปล่า กด "uploading an existing file" แล้วลากไฟล์/โฟลเดอร์ทั้งหมดในนี้ขึ้นไป จากนั้นกด Commit changes
3. สมัคร/ล็อกอิน https://vercel.com ด้วยปุ่ม "Continue with GitHub"
4. กด "Add New..." → "Project" → เลือก repository ที่เพิ่งอัปโหลด → กด "Import" → กด "Deploy"
5. รอ 1-2 นาที จะได้ลิงก์เว็บที่เปิดดูได้จริงจากทุกที่

หมายเหตุ: เว็บที่ได้ยังเป็น "ต้นแบบ UI" — ระบบล็อกอิน/สิทธิ์ยังจำลองด้วย React state ไม่ใช่ระบบหลังบ้านจริง
